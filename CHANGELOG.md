# Changelog

All notable changes to the AI Second Brain skill are documented here.

## [1.1.0] - 2026-05-03

### Changed
- Adapted the skill for GitHub Copilot CLI.
- Updated installation instructions to use `~/.copilot/skills/ai-second-brain`.
- Replaced Claude Code command examples with `copilot` commands.
- Switched the Karpathy wiki instruction file guidance from `CLAUDE.md` to `AGENTS.md`.
- Replaced Claude Code iMessage Channels guidance with Copilot CLI `/remote` guidance.
- Reframed `/today`, `/ideas`, and `/create` as reusable prompt templates for Copilot CLI.

## [1.0.0] — 2026-04-17

### Added
- Initial release.
- Step 1: AI Brain — exports ChatGPT and Claude history into a tagged, linked Obsidian vault.
- Step 2: Karpathy Wiki — sets up `raw/` and `wiki/` folder pair with Karpathy's instruction file.
- Step 3a: MCP connectors for Gmail, NotebookLM and Granola.

- Step 3c: Three slash commands (`/today`, `/ideas`, `/create`) scaffolded automatically.
